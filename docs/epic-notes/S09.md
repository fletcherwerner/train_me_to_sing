# S09 — Full-length match targets, with a report

## Built
- Every match target (Unit A, Pitch finding) listens for the full sing time (`MATCH_SING_SEC` = 8 s, renamed from `MATCH_WINDOW_SEC`; optional `Lesson.singSec` overrides). `matchTarget` runs once at the end; its rule is unchanged. Stop still ends it at once.
- Countdown bar `match-countdown` (`role="progressbar"`); status says "✓ Found it — keep holding" once matched.
- `describeMatch` (pure, `matchScoring.ts`): `foundInSec`, `onAfterFound`, `typicalCents` (octave folded, `wrongOctave` flag), `accuracy`.
- `describeMatchLine` / `describeCents` (`src/ui/describeReason.ts`): the per-target line, shown in the run list (`match-line-N`) and results (`match-result-N`), also inside Today's practice.
- `matchAccuracy(frames, target, singSec)`: first voiced frame to end of sing time (silence after the voice counts against).

## Deviations / assumptions
- `matchAccuracy` signature changed (outcome and holdSec dropped) because the definition no longer depends on them; its tests were rewritten to the new definition.
- Results line per note no longer says "✓ hit/✗ miss"; it shows the S09 line plus "accuracy N%".
- The "mostly …" wording for non-matches uses the folded median cents; wrong octave and silent use the existing miss text.
- Echo yourself still keeps the held stretch (from the match start for `holdSec`).

## Known issues
- E2E for match lessons is slow now (8 s per target).
