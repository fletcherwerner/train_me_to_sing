# E11 — MIDI import

## What was built

- `src/core/exercise/fromMidi.ts`: `summariseTrack` and `toTemplate` (window, monophonic, quantise to 1/4 beat, shift, offsets from the lowest note; throws under 3 or over 400 notes).
- `src/content/midiFile.ts`: parses MIDI bytes with `@tonejs/midi` into beats (using the file's PPQ), first tempo and time signature (defaults 100 bpm, 4/4); only tracks with notes.
- `src/content/importedSource.ts`: `LessonSource` over `StoredData.importedLessons` (zod-validated; bad entries skipped), registered in `registry.ts`; `makeImportedLesson` (stage 3, `imported`, `t3`, 0.8, id `imp-<timestamp>`).
- Store actions `addImportedLesson` and `removeImportedLesson` (also removes progress).
- `/import` screen (`ImportMidi.tsx`): file picker, track list with chord warning (`overlapRatio > 0.3`) and Preview (first 8 bars via `tonePlayer`), title/tempo/bar-range options, summary with fit text, "Add lesson".
- Home: "My songs" section (only when non-empty) with delete + confirmation, and an "Import a MIDI file" link. Imported lessons are listed only in My songs, not under Stage 3, and do not feed the "Continue" card.
- Fixtures `tests/fixtures/c-major-scale.mid`, `two-tracks.mid`, regenerated with `npm run fixtures`.

## Tests
Unit: `fromMidi.test.ts`, `importedSource.test.ts` (fixture offsets, registry, delete removes progress, export/import round trip). E2E: `importMidi.spec.ts`.

## Deviations
- Added dependency `@tonejs/midi` (named by the epic).
- Bar range: first/last bar are 1-based, inclusive, using the file's first time signature.

## Known issues
- Preview plays at the tempo field's value, not the file's original tempo. Pitches are original.
- Tempo changes mid-file and later time signatures are ignored (out of scope).
