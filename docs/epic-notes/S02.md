# S02 — Scrolling pitch graph

## Built
- `src/core/exercise/pitchGraph.ts` (+ test): bounds, time/pitch mapping, target and sung segments, results bounds (C2–C6 cap), axis labels.
- `src/ui/components/PitchGraph.tsx` / `.css`: `PitchGraph` (live, SVG, 8 s window, now line at 30%, scroll group moved by `transform` each frame; sung path `d` rewritten per frame for the visible window only) and `ResultsGraph` (static, scrolls inside its own box past 30 s).
- `Lesson.tsx`: graph above the piano in I do / We do / You do (I do: black only; phrases show only the phrase). Results show the You do graph above the chips.
- `Lesson.css`: on phones (<700 px) the controls row is sticky at the bottom so Stop stays visible.
- Tests: unit, component (Testing Library), `tests/e2e/pitchGraph.spec.ts` at 1280 and 393 px.

## Deviations
- The You do frames are held in `Lesson` component state (in memory, cleared on a new run) rather than inside the session reducer's `youDoResult`; behaviour is the same and the reducer is unchanged.
- Out-of-range markers (▲/▼) are shown when the latest frame (within 0.15 s) is outside the axis.
- On the results graph the axis labels sit in a fixed column left of the scrolling box.

## Known issues
- Not checked on a real iPhone or with a real mic; verified with `sim=` sources only.
