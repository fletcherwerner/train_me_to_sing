# E06 — Full lesson session: I do / We do / You do

## Built

- `core/session/sessionMachine.ts`: pure reducer (`reduce`, `INITIAL_SESSION`) with tests.
- `core/scoring/tips.ts`: `pickTip` (most common miss reason -> one tip) with tests.
- `content/types.ts` (`Lesson`, `LessonSource`), `content/demoLesson.ts` (`0 2 4 2 0`, 60 bpm, t1, pass 0.8).
- `ui/screens/Lesson.tsx` + `Lesson.css`, route `/lesson/:lessonId` (only `demo` resolves). `onAttemptComplete` prop is called after a You do run (no-op now).
- `ui/describeReason.ts` (moved out of `AttemptDev`), `SequenceStrip` gained optional `onChipPress` and a text ✓/✗ mark, `playPreviewNote` in `audio/exercisePlayer.ts`.
- Home links to `/lesson/demo`.
- `tests/e2e/lesson.spec.ts` (perfect, octaveDown, no-range redirect).

## Deviations / notes

- A new `RUN` clears that step's previous result, so stale chips never show on a retry.
- `SHOW_RESULTS` is allowed from You do whenever not running and a result exists (so "See results" works after returning to You do), not only right after a run.
- The mic source is opened once on Start and reused for every run; it is stopped on leaving the screen.
- Redirect to `/range` drops the `?sim` query (unchanged from existing behaviour).
- The e2e lesson specs take about 30 s each (real audio-clock time), with a 90 s timeout.

## Known issues

- Not checked on a real mic or an iPhone.
- Results chips use a 60 px minimum width (`MIN_W_RESULT` in `SequenceStrip.tsx`) so note names and hit/miss marks are not clipped on a phone.
