# E02 — Mic pitch detection and live tuner

## What was built

- **`src/audio/pitch/PitchSource.ts`** — `PitchFrame` and `PitchSource` interfaces exactly as specified in the architecture file.
- **`src/audio/pitch/MicPitchSource.ts`** — Real microphone pitch detection using `pitchy`. Uses `getUserMedia` with echo cancellation, noise suppression, and auto gain all disabled. Connects to an `AnalyserNode` (fftSize 2048) without connecting to speakers. Runs a `requestAnimationFrame` loop that computes RMS, detects pitch via `pitchy`, applies thresholds (clarity ≥ 0.9, rms ≥ 0.01, freq 60–1100 Hz), and applies 5-frame median smoothing. Exports `PITCH_CONFIG` object with all thresholds.
- **`src/audio/pitch/SyntheticPitchSource.ts`** — Synthetic pitch source for testing. Takes a `(tSec: number) => number | null` behaviour function. Emits frames every animation frame with `clarity: 1`, `rms: 0.1`. Includes `constantPitch(midi)` helper.
- **`src/audio/pitch/index.ts`** — `createPitchSource()` factory that reads `sim` from URL query string. If `sim=const:<midi>`, returns a synthetic source; otherwise returns the mic source.
- **`src/audio/pitch/smoothing.ts`** — Pure `smoothPitch(values)` function: takes 5 raw midi values (some null), returns median of non-null ones if ≥ 3 are non-null, otherwise null.
- **`src/ui/components/CentsMeter.tsx`** + **`CentsMeter.css`** — Horizontal bar from −100 to +100 with centre zone of ±toleranceCents, a needle (green inside zone, orange outside), and text showing `♭ 30`, `♯ 12`, or `—` when null.
- **`src/ui/screens/dev/TunerDev.tsx`** — `/dev/tuner` page with Start/Stop buttons, piano keyboard (C2–C6), large note name display, frequency in Hz, `CentsMeter` against nearest key with tolerance 50, debug line showing clarity and rms. Throttles display updates to ~30fps.
- **Routes updated** — Added `/dev/tuner` route. Home page links to both piano and tuner.

## Tests

- `smoothing.test.ts` — Tests `smoothPitch` with various inputs including the spec examples.
- `SyntheticPitchSource.test.ts` — Tests that synthetic source emits frames with configured pitch and null behaviour.
- `tests/e2e/tuner.spec.ts` — Playwright test for tuner page loading and sim mode.

## Known issues

- None beyond the general pitch detection limitations documented in the product overview (octave jumps on low/breathy notes).
