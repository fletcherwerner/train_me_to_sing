# S07 — Clearer next step and a lighter look

## Built

- `src/core/progress/next.ts` (+ test): `nextLesson` (Home's "Next" tag) and `nextLessonAfter` (results "Next lesson"). First built-in lesson not passed/mastered that fits the range; wraps round; imported songs skipped.
- Lesson steps: after one I do play the primary is **Next: We do** (Play again beside it); after one We do run it is **Next: You do** (Sing along again beside it). "Repeat" is gone. `data-testid="run-button"` stays on the play/sing/start button.
- Results: **Next lesson: _title_** (`next-lesson`) after a final pass, **Back to lessons** (`back-to-lessons`) in every non-embedded outcome (primary when it is the last lesson), **Try again** primary when not passed. "Come back tomorrow to finish this one." under the verdict for a first Prove pass.
- `LessonRun` and `MatchRun` take `embedded`; Today's practice passes it, so only "Next part" is primary and the lesson's Next lesson / Back to lessons are hidden.
- `BackLink` ("‹ Lessons", accessible name "Back to lessons") replaces "Home" in the lesson header, Settings, Mic check, Import, Calibrate and the range test.
- Three-part step bar (current filled, finished ticked, later muted); level, help and start note grouped in `.lesson-meta`.
- Tokens on `:root` with dark values (`--bg --surface --border --border-strong --text --muted --success --warn --radius --shadow`); cards, rows, status pills, progress bars under stage/unit headings, "Next" tag and 3px theme left border.

## Deviations / notes

- `dev-page` kept (no rename); `page` not added. Many selectors depend on it.
- Added `--border-strong` (not in the spec): `--border` is a light grey for cards as asked, but a light grey cannot reach 3:1 on white, so controls (secondary buttons) use `--border-strong`.
- `--success` is a darker green than the hit-note fill (#22a55b) so text reaches 4.5:1. The piano, graph and cents meter keep their own colours.
- The forward button is first visually via CSS `order: -1`, not by DOM order.
- The "Next lesson" and Back-to-lessons logic is also applied to Unit A match results (`MatchRun`), which share the screen layout.
- No component test of `Lesson` exists (it needs audio); the primary-button and results rules are covered by Playwright (`tests/e2e/journey.spec.ts`, `practice.spec.ts`).
- Existing specs updated: "Repeat" → "Play again"/"Sing along again"; "Home" link → "Back to lessons"; hardening's exact "Next" → `/^Next: /`.
