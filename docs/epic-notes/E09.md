# E09 — Stage 3 songs with lyrics

## Built

- `src/content/builtin/stage3.ts`: s3-01..s3-05 exactly as in the catalog (notes, lyrics, tempi, `t3`/`t3`/`t3`/`t4`/`t4`), registered in the built-in source.
- `phrases?: Phrase[]` on `ExerciseTemplate` (`Phrase` in `core/exercise/types.ts`); `makeLesson` accepts `phrases`.
- `core/exercise/phrases.ts`: `slicePhrase`, `phraseFor`, `linesFromLengths`.
- `NowSinging` component: bold current syllable, previous one and next two lighter; shown above the keyboard for lessons with lyrics.
- Lesson screen: "Practise" selector (Whole song / Line n) in I do and We do; You do and Results always use the whole song. A We do result is shown on the strip only if it was for the currently selected phrase.
- `SequenceStrip`: chips are a fixed 56px high, the strip is capped at three rows (176px) and scrolls itself (not the page) to keep the current chip visible.
- Results: "Line n: k missed" list (`missed-by-phrase`) above the per-note list.
- Tests: `core/exercise/phrases.test.ts`, `content/stage3.test.ts`, `ui/components/NowSinging.test.tsx`, `tests/e2e/stage3.spec.ts`.

## Phrases chosen (note counts per line)

Hot Cross Buns 3/3/8/3; Mary 7/6/7/6; Ode to Joy 15/15; Twinkle 7×6; Frère Jacques 8/6/12/6.

## Notes / assumptions

- Phrases are authored as consecutive lengths; only Twinkle was specified, the others follow the lyric line breaks.
- `slicePhrase` drops any rest before the phrase's first note; `totalSec` is end of last note minus start of first.
- The lead-in is unchanged (`playExercise`), so phrases get 4 clicks at the song's tempo.
- A phrase practice score is not saved; only the You do whole-song attempt is.
- Stage 3 intro keeps the existing generic text; Frère Jacques needs a 14-semitone range and shows the existing "doesn't fit" message otherwise.
- Test files for phrase logic live in `core/` only where they use no content imports; the content-based checks are in `src/content/stage3.test.ts`.

## Known issues

- Melodies were not listened to; the owner must check all five by ear (review step 3). Nothing in the note data was altered.
- Frère Jacques ends with "ding dang dong" on `0 -5 0:2`; the data was kept as in the catalog.
- The iPhone no-page-scroll fit (review step 6) has not been checked on a device.
