# E12 — Capacitor iOS wrapper

## Built

- `@capacitor/core`, `@capacitor/ios` (dependencies) and `@capacitor/cli` (dev), v8.6.2.
- `capacitor.config.ts` (`appName` "Train Me To Sing", `webDir` `dist`, placeholder `appId` `com.example.trainmetosing`).
- `ios/` project (SPM). `Info.plist`: microphone usage text, display name, portrait only. `AppDelegate`: `playAndRecord` + `measurement`, no options. Icon and launch screen generated from the E10 icon by `npm run icons`.
- Scripts `ios:sync`, `ios:open`. Service worker registration is skipped when `Capacitor.isNativePlatform()`.
- `docs/ios-build.md` for the owner.

## Deviations

- **Bundle id is a placeholder.** The owner has not supplied one; change it in `capacitor.config.ts` and in Xcode.
- **`cap add ios` was not run as such.** This machine has no CocoaPods, and the CLI (8.6.2) mishandles `--packagemanager SPM` (it lowercases the value, then compares to `'SPM'`, so it falls back to CocoaPods). I extracted the CLI's own `ios-spm-template.tar.gz` into `ios/` and applied the id/name changes by hand; `cap sync ios` then ran cleanly. Removed the template's `CapApp-SPM/README.md` (one-README rule).
- Deployment target is the template's iOS 14.0.

## Not verified (needs the owner / Xcode)

- Nothing from the device checks (mic prompt once, three audio paths, calibration, interruptions, share sheet/file picker) has been run. No latency/dropout measurements exist; if WKWebView audio proves inadequate, record them here and propose a native `PitchSource`/`TonePlayer` plugin epic.
