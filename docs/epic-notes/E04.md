# E04 — Exercise model, range fitting, "I do" playback

## What was built

- `src/core/exercise/types.ts`, `notation.ts` (`parseNotation`), `fit.ts` (`fit`, `displayRange`), `timeline.ts` (pure `buildTimeline`, `LEAD_IN_CLICKS`).
- `src/audio/metronome.ts` (`scheduleClick`, `stopClicks`), `src/audio/exercisePlayer.ts` (`playExercise`).
- `src/ui/hooks/usePlaybackPosition.ts`, `SequenceStrip`, `BeatIndicator`, `/dev/exercise` (`ExerciseDev.tsx`), Home link.
- Tests: `src/core/exercise/exercise.test.ts`, `tests/e2e/exercise.spec.ts`.

## Deviations / notes

- `LEAD_IN_CLICKS` lives in `core/exercise/timeline.ts` (pure, testable) and is re-exported from `audio/exercisePlayer.ts`.
- Starting a new playback stops any playback still running.
- `totalSec` is the end of the last note (trailing rests are not included).
- The fit property test uses inline templates; the lesson catalog does not exist yet.

## Known issues

- Play is disabled during playback; Repeat restarts from the count-in.
- Audio timing was checked in headless Chromium only, not by ear or on iPhone.
