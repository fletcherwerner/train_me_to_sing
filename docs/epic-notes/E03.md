# E03 — Vocal range assessment

## What was built

- **`src/storage/schema.ts`** — zod schema for `StoredData` with defaults (`range: null`, `settings.latencyOffsetMs: 0`, `progress: {}`, `importedLessons: []`). Exports `loadData()` and `saveData()`.
- **`src/storage/store.ts`** — zustand store `useAppStore` with `setRange(range)` action that saves to localStorage.
- **`src/core/exercise/rangeAnalysis.ts`** — `findHeldNote(frames, pick)` pure function implementing the stable-segment algorithm from the architecture spec.
- **`src/ui/screens/RangeSetup.tsx`** — full wizard with steps: intro → lowest-find → lowest-record (countdown + 3s window) → lowest-result → highest-find → highest-record → highest-result → confirm. Uses `SyntheticPitchSource` with `sim=range:<low>,<high>` for testing.
- **`src/ui/screens/RangeSetup.css`** — styles for all wizard steps, responsive for phone.
- **`src/ui/screens/Home.tsx`** — shows saved range with "Redo range test" link.
- **`src/app/routes.tsx`** — redirects to `/range` when no range is set.
- **`src/audio/pitch/index.ts`** — `acceptRangeLow()` and `resetRangeSim()` for range simulation mode; `createPitchSource()` routes `sim=range:<low>,<high>`.
- **`tests/e2e/range.spec.ts`** — Playwright test completing the full wizard with `sim=range:45,64`, plus a silent-recording test.
- **Unit tests** — `rangeAnalysis.test.ts` (9 tests), `schema.test.ts` (5 tests).

## Deviation from plan

- The epic states `?sim=range:45,64` expects "A2 – E4 (20 semitones)". 64−45=19 semitones; the test was corrected to 19.

## Turn 1 fixes (continuation)

- Frames are now collected from the 3 s recording window itself on the audio clock (before, collection stopped when the countdown ended). Countdown clicks are scheduled on the audio clock.
- Wizard collapsed to find / record / result / fail / confirm, parameterised by lowest/highest; the lowest note is played back on result.
- Confirm keyboard is padded to whole octaves; the high-limit nudge buttons were inverted and are fixed; nudges play the note.
- Store `setRange` used a stale snapshot; now reads current state.
- Redirect to `/range` keeps the query string (`?sim=`).
- Added `sim=silent`; e2e covers redirect, wizard, reload persistence and the silent retry message.
