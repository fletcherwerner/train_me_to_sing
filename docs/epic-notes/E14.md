# E14 — Beginner path: new Stage 1, feedback levels, echo yourself

## Built

- **Content** (`src/content/`): `Lesson` gained `kind`, `unit`, `levels`, `echo`, `matchTargets`, `holdSec`, `landWithinSec`. `builtin/stage1.ts` is now the 19 new lessons (units A–D, ids `s1a-01`…`s1d-03`). Stages 2–3 and imported songs get `kind: 'melody', levels: false, echo: false` (imported lessons already in storage are defaulted in `importedSource.ts`). Match lessons carry a one-note placeholder `exercise` so Home can fit them.
- **Core**: `core/exercise/fit.ts` (`opts.tonicMidi`, `pickTonic`); `core/scoring/matchScoring.ts` (`matchTarget`, `scoreMatch`, `placeTarget`, `describeMatchMiss`); `core/scoring/bestTake.ts` (`qualifiesForEcho`); `core/session/sessionMachine.ts` (`Level`, `createSession`, `ADVANCE`, `STEP_DOWN`).
- **Storage**: progress entries gain optional `level` (highest unlocked). `recordAttempt(id, result, level?)` — with a level, only a Prove pass sets `passed`; a pass below Prove unlocks the next level. Old `s1-01…s1-08` progress is dropped on load (and written back), on import and on profile load (`schema.ts dropLegacyProgress`); `notices.ts` holds the one-time Home notice. Storage `version` is still 1.
- **Audio**: `audio/takeRecorder.ts` (MediaRecorder on the mic stream, `audio/mp4` preferred, decode + trim, synthetic sine take for `?sim=`); `PitchSource.getStream?()`; `exercisePlayer` gained `melodyBuffer`, `playNoteClip`, `playBufferClip`; `audio/pitch` gained `isSimulated()` and `wantsRandomKey()`.
- **UI**: `Lesson.tsx` runs Learn / Practise / Prove, a new key per Practise/Prove attempt, "Starting on X", step-down and advance buttons, and Echo yourself. `MatchRun.tsx` is the Unit A screen. `Home.tsx` groups Stage 1 by unit with per-unit counts, shows the level reached, and shows the rebuilt notice. `LessonHeader` moved to `ui/components/`.

## How the pieces behave

- Learn is the old I do / We do / You do with the centred key. Practise and Prove open at You do (I do / We do via Back) and pick a new key per attempt (`avoid` = the key just used). Practise hides the sung key, the red line and the cents meter; Prove also hides the graph, target labels and note strip, and lights only the starting note before the count-in.
- Echo yourself: We do and You do runs of `echo: true` lessons record the mic. A run qualifies when every note is a hit with a median within 25 cents. A You do take replaces any take; a We do take only fills an empty slot or replaces an older We do take. Echo plays the take in place of the piano through `playExercise({ melodyBuffer })` and scores a We do-style run against the take's own exercise (same key). It is never saved. Unit A echoes the last matched hold as a single match target.
- `?sim=` keeps the centred key and the placement's centre unless the URL adds `&key=random`.

## Deviations and assumptions

- Match `timeToMatchSec` is measured from the start of listening to the start of the matching hold. A pause of at most 0.15 s in the pitch does not restart a hold (the detector drops frames); an off-pitch frame does.
- The passed-but-not-Prove results screen reads "Level passed" (not "Passed"); only a Prove pass (or a non-levelled lesson) reads "Passed".
- Imported lessons stored before E14 have no `kind/levels/echo`; `importedSource` fills the defaults.
- Echo for Unit A uses the matched hold only (about 1 s), not the whole 8 s window.
- The mic take is trimmed using the audio-clock time at `MediaRecorder.onstart`; recorder start latency (tens of ms) is not compensated.
- Added no runtime dependencies.

## Known issues

- Echo yourself with a real microphone could not be exercised here (no mic in the test browser); only the synthetic take path is covered by Playwright. Please check it on iPhone Safari (`audio/mp4`).
- If a student goes Back to We do at Practise or Prove, the We do result graph is drawn against that visit's key, which can differ from the key the earlier We do run used.
- The `s1a-*` silent test takes about a minute because each target waits the full 8 s.
