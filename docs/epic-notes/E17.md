# E17 — Practice insights: activity, weekly goal and a performance dashboard

## Built

- **Run log.** `src/core/insights/types.ts` (`RunRecord`, `NoteRecord`, `History`), `history.ts` (retention, merge, practice seconds). `StoredData.history` is optional in the file and defaults to `{ runs: [], days: {} }`; the version stays 2. `store.recordAttempt(..., run?)` writes progress and the run in one `commit`; `logRun` (warm-up) and `addPracticeSeconds` are new actions. Reset progress also clears the history. Export carries it; Import replace takes it as is; Import merge unions runs by `id` and takes the larger `seconds` per day. Profiles (`ProfileData.history`, `FRESH_DATA`) and the dev-server profile API carry it; older profile files without it load.
- **Spread.** `spreadCents` on `NoteResult` (`evaluate.ts`, IQR of the voiced frames' cents in the note) and on `describeMatch` (frames after the first voiced one, octave folded). It changes no hit, miss or score.
- **Activity.** `activity.ts`: Monday–Sunday weeks, `activeDays`, `weekSummary` (count, 7 booleans, last week, `goalMet`, streak), `weekSeconds`.
- **Categories.** `categories.ts`: the nine categories from the epic, thresholds in `THRESHOLDS`, `FULL_MINIMUMS` and `RUN_MINIMUMS`, evidence text, tips, `QUIET_NOTICE`. `runFocus.ts` (max 2, Learn = 1, positive line). `summary.ts`: Today card, patterns, improvements, weekly trend, best runs.
- **Practice time.** `practiceClock.ts` (pure) and `ui/hooks/usePracticeTime.ts`: counts while a lesson, Match, warm-up, Today's practice or Progress screen is open and the page is visible (`visibilitychange`, and Capacitor `appStateChange` on iOS); stops 2 minutes after the last input unless a run is in progress; saves in chunks of 15 s or more while ticking, and whatever is there on leaving, hiding and at each run end.
- **UI.** `Progress.tsx` at `#/progress`; `WeekRing`; `RunFocus` ("Focus next", `data-testid="run-focus"`) on melody and Match results (and inside Today's practice, without lesson links); Home gets the `home-week-ring` link and a "Progress" nav link.

## Category → suggested lesson

flat, sharp, high → `s1a-02` Low, middle and high · unsteady, finding → `s1a-01` Find one note · sliding → `s1a-03` Land right on it · leaps → `s1b-06` Do–mi–sol · drift → `s1d-03` Up and back down · timing → `s1b-04` Do–re–mi. The link is only shown when the lesson exists and is not the lesson just sung.

## Size of the log

A melody run record with 5 notes is about 0.5–1 KB of JSON; a Match run with 5 targets is about the same. 8 weeks of heavy use (say 30 runs a day) is about 1,700 runs ≈ 1.2 MB before pruning; notes are dropped from runs older than 8 weeks and the log is capped at 3,000 runs, so the worst case is about 2–3 MB, inside the usual 5 MB localStorage limit and trivial for the iPhone file. A typical learner (5–10 runs a day) is well under 0.5 MB.

## Deviations

- **Wrong-octave advice kept.** The focus section replaces the `pickTip` line on melody results, but wrong-octave notes are excluded from every pitch category, so the old tip would be lost. The melody results still show the `results-tip` line, and only when a note was a wrong octave.
- **Per-day minimums for patterns** use the run-level (scaled) minimums, because the full minimums (8 voiced notes) are too high for one day of a beginner's practice. "Flagged on at least half of the days that had enough data" is judged that way; the window itself uses the full minimums.
- **Drift** is counted per direction: the runs that drifted the commonest way over the runs that qualified.
- Only a finished warm-up (all three glides, "Finish warm-up") is logged. Unscored parts of Today's practice other than the warm-up (the wrap-up) are not runs. Ids `practice:<part>` are not used.
- Lessons mastered "recently" use the latest proof date of a passed lesson within the last 14 days.
