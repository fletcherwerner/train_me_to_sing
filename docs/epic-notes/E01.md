# E01 notes

Built: Vite/React/TS scaffold (strict, basicSsl, `base: './'`), `core/music/notes.ts`, `audioEngine`, `tonePlayer`, `PianoKeyboard` (SVG), HashRouter with `/` and `/dev/piano`, ESLint core-isolation rule, vitest and Playwright tests.

Deviations: none. Vitest runs under jsdom with Testing Library (dev deps added for the component render test). Playwright starts `npm run dev` itself and ignores the self-signed cert.

Known issues: key sizes derive from the SVG viewBox, so very narrow screens with many keys give small keys (about 24 px per white key at 360 px with 15 white keys). Pitch of notes was not verified by ear.
