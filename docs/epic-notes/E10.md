# E10 — PWA install, hosting, export/import

## What was built

### PWA
- `vite-plugin-pwa` (`registerType: 'autoUpdate'`, precaches all build assets). Manifest: "Train Me To Sing" / "Sing", standalone, portrait, theme and background `#1f3a5f`, icons 192, 512 and maskable 512 in `public/icons/` (SVG source plus PNGs; `scripts/` holds the generator).
- `index.html`: `apple-touch-icon` (180 px), `apple-mobile-web-app-capable`, status-bar style, `viewport-fit=cover`.
- `src/app/registerServiceWorker.ts` registers the worker (production only) and `UpdateBanner` shows "Update ready — reload" when a new version takes over.

### Hosting
- `.github/workflows/deploy.yml`: on push to `main`, install, lint, unit tests, build, deploy `dist/` to GitHub Pages. `base: './'` and `HashRouter` give sub-path hosting; the worker is registered with scope `./`.

### Export / import
- `src/storage/exportImport.ts`: `exportData`, `parseImport`, `summarizeImport`, `mergeData`, `replaceData`, `saveExport` (Web Share with a file, else download). Store action `importProgress(incoming, mode)`. Settings has Export, Import, and a Replace/Merge dialog with a summary. `latencyOffsetMs` is never imported.

### iOS polish
- Safe-area insets, `touch-action: manipulation`, `user-select: none`, `useWakeLock` during a run, and `visibilitychange` stops a run and shows "Paused — tap to restart".

## Tests
- Unit: merge rules (including unknown lesson ids), round trip, invalid JSON and wrong schema.
- E2E: build contains manifest and `sw.js`; built app served by `vite preview` reloads offline; import via file picker and export download.

## Fixes this turn
- The service worker was never registered: registration waited for `load`, but it runs from a React effect after `load` had fired. It now registers immediately when the document is already complete.
- `vite preview` for the offline test runs over plain `http://localhost:4173`. A self-signed certificate blocks service worker registration in Chromium. The dev server still uses basic-ssl.

## Deviations
None.

## Known issues / not verified
- Not tested on a real iPhone or on GitHub Pages: no push access from here. The owner must follow the review script on a device.
- Mic permission in standalone mode: not verified on device. Expected on iOS: the prompt may reappear on each launch of the home-screen app. Please record what actually happens during review.
- Wake lock and background pause are covered by code only, not by e2e.
