# E05 — Scoring engine and graded "You do"

## Built

- `core/scoring/`: `types.ts`, `tolerance.ts` (t1–t4, `TOLERANCE_FLOOR`, `getTolerance`), `evaluate.ts` (`evaluateAttempt`, pure), `scoring.test.ts`.
- `audio/pitch/frameRecorder.ts` (`recordFrames`), `audio/pitch/simSinger.ts` (sim behaviours: perfect, flat40, flat70, octaveDown, late300, wobble, silent). `createPitchSource` maps `?sim=<behaviour>` to them; the attempt page registers the exercise and start time with `registerSimExercise`.
- `ui/hooks/useLiveAttempt.ts`, `ui/screens/dev/AttemptDev.tsx` at `/dev/attempt`.
- Tests: `scoring.test.ts`, `frameRecorder.test.ts`, `tests/e2e/attempt.spec.ts`.

## Deviations / notes

- `evaluateAttempt` takes a structural `ScoredFrame` (`tSec`, `midi`) so `core` does not import from `audio`; `PitchFrame` satisfies it.
- If a note passes the median, octave and hold checks but no 80 ms on-note run exists in the onset search, it is reported as `wavered`.
- `useLiveAttempt` accepts the tolerance per the spec, but the profile is only applied by the page's `CentsMeter`.
- The attempt page's exercise dropdown has three dev templates (three notes, scale, repeated note).
